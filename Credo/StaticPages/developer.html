Startup and shell

Program.cs builds a Blazor interactive-server app and then runs a one-off SQL statement before app.Run().

  1. Register Razor components with interactive server rendering.
  2. Singleton: AppConfig, IDbContextFactory / DbContextFactory.
  3. Scoped to the circuit: Repo, State, UpdateService, GraphService.
  4. Outside Development: exception handler, HSTS, and AppConfig.StartBrowser with the Kestrel URL from appsettings.json (http://localhost:5123). Development does not open that browser. launchSettings.json launches http://localhost:5183 itself.
  5. Pipeline: status-code re-execute to /not-found, HTTPS redirection, antiforgery, static files, static assets.
  6. MapGet("/help.html") and MapGet("/developer.html") read the matching file from the content root StaticPages folder and return text/html; charset=utf-8. They are not files under wwwroot. Credo.csproj also copies StaticPages\**\* to the build output.
  7. MapRazorComponents<App>().AddInteractiveServerRenderMode().
  8. On application stopping, AppConfig.StopBrowser closes the process started in step 4.
  9. Open one scope, create a CredoDbContext, and run raw SQL that creates WatchlistItems when sysobjects has no such user table. There is no EF migration for any table.

The document shell is Components/App.razor. It loads Bootstrap, app.css, scoped CSS, Blazor, Script/Javascript.js (the file on disk is wwwroot/Script/JavaScript.js; Windows matches it), and Chart.js 4 from a CDN. Routes and HeadOutlet use interactive server mode.

Components/Layout/MainLayout.razor renders Menu, then the page body, then DialogBox. Every page therefore shares the menu and the dialog. Menu.razor sets @rendermode InteractiveServer on itself as well.

Config and database

AppConfig reads configuration once in its constructor.

  • MachineName is Environment.MachineName.
  • SqlInstance is SQL16 when the machine is ROG, otherwise SQL.
  • DbName stays Credo. ConnectionKey starts as XPS.
  • BackupPath and DownloadsPath come from Paths:Backup and Paths:Downloads, with environment variables expanded. Downloads is %USERPROFILE%\Downloads\Credo\.
  • BrowserPath is Paths:BrowserROG or Paths:BrowserXPS.

DbContextFactory.CreateDbContext picks the first non-empty connection string among ConnectionKey (XPS), the machine name, and Local. It replaces [ServerName] with {MachineName}\{SqlInstance} and [DatabaseName] with DbName. Development turns on sensitive data logging. A missing string throws and names the user-secrets command.

CredoDbContext has one DbSet per entity and no OnModelCreating. Relationships are convention from the foreign-key properties: Transaction.SecurityID, Security.TickerID, Security.CurrencyID, Portfolio.SecurityID, Portfolio.CurrencyID. The watchlist set is named WatchlistItems, which is also the table the startup SQL creates.

Reads and writes

Repo is the read side and the scope factory. Each GetEntityNTAsync / GetEntitiesNTAsync / AnyEntityAsync opens a context, runs, and disposes it. Those reads use AsNoTracking. A write that must see its own changes uses BeginScope.

await using var scope = repo.BeginScope();
var rows = await scope.GetEntitiesAsync<Security>();
scope.Add(entity);          // or AddRange / RemoveRange
await scope.SaveChangesAsync();

RepoScope holds one context until dispose. Its gets are tracked. RepoQuery.BuildQuery adds the same includes and default order for both read and write queries:

TypeIncludes and order
Portfoliosecurity.Transactions, security.ticker, currency. Ordered by ticker name.
Securityticker, currency, Transactions. Ordered by ticker name.
TransactionNo include. Ordered by trade date.
Ticker, CurrencyOrdered by name.
HistoryOrdered by date.
WatchlistOrdered by symbol.

A caller that passes sort adds another OrderBy after that default. GetEntityNTAsync without a filter calls SingleOrDefaultAsync, so an unfiltered single-entity read throws when the table has more than one row.

History identity in code is the pair (Symbol, Date). The database has no unique constraint on that pair. Writers keep a HashSet and skip a key they have already seen.

How the rows connect

EntityRole in a flow
TickerYahoo symbol, display name, and a currency string. Import and history jobs iterate these symbols. USDUSD=X is skipped by the live price update.
CurrencySymbol is what Yahoo is asked for. Name is what tickers, expenses, and new portfolio rows match on. Rate is USD per 1 unit of that currency after an update. Expenses multiply a local amount by Rate.
SecurityOne row per ticker that Securities import created. SecurityName is copied from the ticker name and is the string transactions and portfolio rows match. Live update overwrites Price, PrevClose, Currency (from snapshot.Currency.Name), exchange, change, dividend yield, EPS, PE, forward PE, and market cap. A snapshot miss sets Price = 1 and leaves the other quote fields.
TransactionOne statement line. Security is the name text. SecurityID is the link, filled later. Note is stored by the PDF import and read by no page. Codes are stored as the PDF wrote them; the parser only accepts two lowercase letters.
PortfolioOne holding. Security_Description is the match key for the holdings PDF. Quantity and market value are replaced from that PDF. Unit_Cost and Cost are written for new rows and left alone by later recalculation. Price, Market_Value, Gain, GainPerc, Pct, and IRR are rewritten by UpdatePortfolioAsync. Market_Value_Yesterday is not mapped: for currency USD=X it is previous close (or price) times quantity; otherwise it is security.PrevClose times quantity times the current currency.Rate.
HistoryPrice by symbol and date. Symbol Portfolio is the whole-book total for a day, cash included, written by AppendPortfolioHistoryAsync for today. Symbol CASH is one month’s USD cash total, dated the 25th, written by portfolio import. Symbol ^GSPC is the S&P 500 series used as the chart benchmark and the securities-page comparison.
WatchlistSymbol and name only. Prices on that screen are live and are not written onto the watchlist row. History for the symbol is stored in History.

Two currency strings sit side by side. Transaction and expense rows use ISO-style codes such as GBP. After a Yahoo update, Security.Currency and Portfolio.Currency hold snapshot.Currency.Name, and the portfolio math treats the value USD=X as “already in dollars”. Cash holdings with an empty security currency are classified by description prefix in UpdateService.Cash: Australian dollar, pound sterling, euro, or US dollar become AUD=X, GBP=X, EUR=X, or USD=X.

Dialog bus

State is a scoped event hub. DialogBox subscribes in OnInitialized and unsubscribes on dispose. Because both are created for the same circuit, a page can ask for UI without a component reference.

State methodDialog behaviour
ShowFileUpload(title, message, accept)Shows the file picker. InputFile copies the stream into a byte[] before the Blazor event returns, capped at 10 MB. The task completes with those bytes, or with null when the close button runs. Dispose also completes a pending upload with null.
ShowProgress / UpdateProgress / HideShows the same dialog as a progress bar. UpdateProgress clamps the value to 0–100 and can replace the title.
ShowMessage(title, message, button)button == "Ok" shows Ok. button == "YesNo" shows Yes and No. Yes and No complete the task with those strings. Ok calls Cancel, which closes the dialog and completes a pending file task, and does not complete the message task.
ShowFilePickerInvokes FileNameGet. DialogBox never subscribes that event.
Update Failed waits on Ok. UpdateService.UpdateSecuritiesAsync catches a Yahoo or save failure, hides progress, then await state.ShowMessage(..., "Ok"). The Ok button does not finish that task, so the update method stays on the await and its finally does not run. PortfolioView.RefreshAsync is awaiting the same call, so the refresh button stays on “Refreshing…” for that circuit.

Import

All six buttons live in ImportView.razor.cs. A success path sets Results.Records, shows “Imported: N records” for five seconds, then clears the result. The button flags b1–b6 turn the button red and are never cleared. Transactions and Portfolio set their flag only after a file is accepted. A thrown exception is logged and added to Results.Errors. Closing a PDF dialog returns -1 and the caller shows nothing.

Tickers

  1. Require DownloadsPath. Take the first file matching Ticker*.csv. Either miss shows Imported: 0.
  2. CsvHelper with invariant culture, comma, trim, blank lines ignored, bad and missing fields ignored. TickerMap reads columns ticker, securityname, currency into Symbol, Name, Currency.
  3. Insert rows whose Symbol is not already in Tickers. Existing symbols are left as they are.

Currencies

  1. First Currencies*.csv in the same folder.
  2. CurrencyMap reads currency into Name and symbol into Symbol. Rate is not mapped.
  3. Match an existing row on Symbol. A match copies Symbol and Name and leaves Rate. A new row with Name == "USD" gets Rate = 1; any other new row keeps the default 0 until Update All fills it from Yahoo.

Securities

No file. Load every ticker and a dictionary of Currency.Name → id. For each ticker whose id is not already a Security.TickerID, add a security named from the ticker, with CurrencyID when Ticker.Currency equals a currency name. Save. Then, for those new names only, set Transaction.SecurityID where Transaction.Security equals SecurityName.

Transactions PDF

  1. ShowFileUpload("Import transactions", ..., ".pdf").
  2. ReadPdfRows opens the bytes with PdfPig. Words on a page are grouped into lines when their bottoms are within 3 points, then sorted left to right.
  3. A line whose first word is Code records that word’s left edge. Lines that are empty, all digits, or that contain the statement chrome (Sanlam, Lamprecht, “Transaction Summary”, “From ”, the column header, “Tran ”) are dropped.
  4. A line that matches the transaction regex becomes a row: two-letter code, body, trade date dd/mm/yy, optional settle date, optional quantity, three-letter currency, amount. The body is split at the first all-caps token into description and security.
  5. A non-matching line is attached to the previous row. If it starts 60 points or more to the right of Code, it is appended to the security name. Otherwise it is appended to Note.
  6. SaveTxRowsAsync loads existing (TradeDate, LocalAmount) pairs. A blank code, a blank date, or a date that still will not parse is skipped. DateRegex rewrites d/m/yy to yyyy-mm-dd and is called twice on the trade date. Two-digit years become 20yy. A pair already stored is skipped. New rows are inserted with the code unchanged, the note, and a quantity parsed as int or rounded decimal. When the code is lo and that quantity is null or 0, the note replaces the security and the note is cleared.

Portfolio PDF

  1. ShowFileUpload("Import portfolio", ..., ".pdf"). No holdings in the file adds the error “No holdings found in the PDF.” and returns -1 without writing.
  2. A header line that contains the word SecurityDescription records left edges for Quantity, that word, UnitCost, Price, Cost, MarketValue, Pct, and P&L. A header missing any of those words is ignored.
  3. Later lines drop words more than 80 points left of Quantity. Words are bucketed at the midpoints between headers. Quantity is every word whose right edge is more than 2 points left of SecurityDescription. A line with a blank security, or a quantity that is not a number, is skipped. That drops account lines, subtotals, and totals.
  4. UpsertPortfolioAsync skips a blank description, a null or zero market value, and the description CONSTELLATION SOFTWARE-WT 40. Those names are not marked seen, and they add nothing to the cash total.
  5. A kept row whose description starts, without regard to case, with US DOLLAR, POUND STERLING, EURO, AUSTRALIAN DOLLAR, or CANADIAN DOLLAR adds its market value to a cash total. IsCashDescription does that test. The holdings PDF market value is already in USD.
  6. A description already on a portfolio row updates only Quantity and Market_Value.
  7. A new description is inserted with the PDF figures. If a security has the same SecurityName, the row copies that security’s id, currency id, and price. Otherwise the first word of the description is mapped (australian and us → USD, euro → EUR, pound → GBP, anything else → USD), the currency id is looked up by Currency.Name, and price is set to 1.
  8. Every existing portfolio description that was not seen is deleted. A skipped line therefore removes an older row of the same name.
  9. UpsertCashHistoryAsync rounds that total to 2 decimals. The date is the 25th of DateTime.Today. It loads History with Symbol == "CASH" and that date. No row inserts one. A row replaces Price. SaveChangesAsync then writes the portfolio updates, inserts, deletes, and this history row together. The imported-record count includes the history change.

Link Trans

  1. Group securities by SecurityName. One row in the group supplies the id. Several rows supply the id whose Exchange == "Milan". No Milan row adds a warning and that name is not linked.
  2. Load transactions that have a Security string present in that map. Update a row whose SecurityID is null, or whose id is one of a duplicated name and is not the chosen id.
  3. The record count is SaveChangesAsync, so it counts every changed column EF writes, not the number of PDF lines.

PortfolioMap and TransactionMap in Classes/Classes.cs describe CSV columns. No import registers them. Transaction import is the PDF path only.

Price updates

Menu handlers are in Menu.razor / Menu.razor.cs. Update All is UpdateService.UpdateSecuritiesAsync. The portfolio Refresh button calls that and then reloads portfolio rows.

Update All

  1. ShowProgress("Updating Securities").
  2. Load tickers except symbol USDUSD=X, and every watchlist symbol. One YahooQuotesBuilder().Build().GetSnapshotAsync asks for the union. While that task runs, a one-second timer advances the bar from 10 toward 80.
  3. In one scope, for each security with a ticker: copy currency name, regular price, previous close, exchange, change percent, dividend yield, EPS, trailing PE, forward PE, and market cap from the snapshot. A missing snapshot sets Price = 1.
  4. For each currency whose name is not USDUSD=X, set Rate from the snapshot of Currency.Symbol. A miss leaves the old rate. Save.
  5. UpdatePortfolioAsync.
  6. AppendPortfolioHistoryAsync sums portfolio Market_Value, rounds to 2 decimals, and inserts or overwrites the History row Symbol = "Portfolio" for today. It does not write symbol CASH.
  7. SyncAllHistoryAsync walks every ticker and watchlist symbol. When the latest stored date is before yesterday, it calls Yahoo history from that date (or from five years ago when the symbol has no rows) and appends missing (Symbol, Date) keys. It then inserts today’s price from the snapshot already in memory when that key is new. An existing today row is not updated. A Yahoo rejection for one symbol is swallowed.
  8. The bar goes to 100 and Hide runs in finally, unless the catch path is stuck on the Ok dialog described above.

Recalculate Portfolio

UpdatePortfolioAsync does not call Yahoo. For each portfolio row in one scope:

  1. Remember total as the sum of Market_Value already stored, before any row is rewritten.
  2. Set Currency from security.Currency, or from Cash(description) when that is empty.
  3. Set Price from security.Price.
  4. Market value is Price * Quantity when currency is USD=X. Otherwise it is Price * Quantity * security.currency.Rate.
  5. Gain = Market_Value - Cost. Cost stays at the imported figure.
  6. GainPerc is null when Price == 1. Otherwise Gain / Cost * 100.
  7. Pct = new Market_Value / total * 100, using the total from step 1.
  8. From the security’s transactions, buys and long-ins add quantity, sells and long-outs subtract it. Both comparisons are lowercase. When shares remain, a cv transaction is added in memory only, dated today, amount shares * security.Price. XirrCalculator.CalculateXirr runs on that list. A finite result is stored on Portfolio.IRR as percent (rate * 100).

Editing a quantity on the portfolio saves the integer, calls this method, reloads, and turns the dollar columns on. It does not call Yahoo.

Recalculate XIRR

Menu.UpdateSecuritiesXIRR loads every security in one scope. For each, it sums lowercase by/li against sl/lo. A positive remainder adds an in-memory cv row of remainder * security.Price. Security.XIRR is set to rate * 100 when the result is not NaN. Save, then navigate to /portfolio. Yahoo is not called. This is the value the securities page shows in the CAGR column. The securities page does not write XIRR itself.

Rebuild history

Rebuild Securities History is UpdateHistoryAsync. Rebuild Watchlist History and the watchlist Update History button are UpdateWatchlistHistoryAsync. Both load existing history keys, then for each symbol fetch Yahoo daily history from the last stored date, or from five years ago when there is none. They insert missing keys only. After the loop they take one more snapshot and insert today when that key is new. They do not delete old rows, and they do not refresh a today row that already exists. FetchTickerHistoryAsync uses each tick’s close and DateOnly from the tick’s UTC date. An exception on one symbol is ignored.

Portfolio screen

PortfolioView.OnInitializedAsync loads portfolios through the no-tracking read, so each row already has security, ticker, transactions, and currency. It sets lastUpdated to now. FormatRelative still returns Not Yet while the static field IsUpdated is false. That flag is static, so it is shared by every circuit in the process. Refresh sets it true before the Yahoo call and sets lastUpdated after UpdateSecuritiesAsync returns.

hasRefreshed starts false. Dollar cells and the totals table render only when it is true. The eye toggles it. A saved quantity sets it true. Refresh does not.

Sorting is in memory on the loaded list. Security name opens TransViewMod with a cloned list: buy and long-in amounts are negated, sell and long-out quantities are negated, an M-Val row is appended when the signed quantity is positive (quantity * price), and a Gain row is the signed sum, multiplied by security.currency.Rate unless the last transaction currency is USD=X. Clicking the popup clears it. Those extra rows are not saved.

The Ex checkbox stores portfolio ids in a page field. The toolbar chart passes the related security ids into ComputePortfolioChartAsync when the set is not empty. With an empty set it calls LoadTickerDataAsync("Portfolio", null), which reads History rows for symbol Portfolio. That series only contains days AppendPortfolioHistoryAsync has written. BackfillPortfolioHistoryAsync can rebuild the whole series and is not called from any page.

The toolbar chart passes cost base 1339055 and StartAtFirstBuy = false. A row chart passes a null cost base and StartAtFirstBuy = true.

Securities screen

  1. Load every History row for ^GSPC into a date → price dictionary, last row winning on a duplicate date.
  2. Load securities whose ticker symbol is null or does not end with =X.
  3. Load portfolio rows with Quantity > 0 and keep their security ids. The name is blue when the id is in that set and the row is not the selected one.
  4. ComputeGainPerc sets the unmapped GainPerc: (market value of remaining shares + sell proceeds − buy cost) / buy cost, using lowercase by/li/sl/lo. Null when buy cost is not positive.
  5. ComputeSpyPerf sets unmapped SpyPerf only when the first by or li is at least 365 days ago. It calls CalculateSpyXirr with the security’s transactions, the S&P dictionary, and the currency rate (1 when Security.Currency is USD=X). The column is green when XIRR >= SpyPerf.

The CAGR column is the persisted Security.XIRR, and it is blank under the same one-year rule. Gains reloads tracked securities, runs ComputeGains, the two computes above, and saves. ComputeGains adds an in-memory cv when shares remain, sums signed local amounts for by, li, lo, sl, dv, in, and cv, then sets Gain to that sum times currency.Rate unless Security.Currency is USD=X. Gain is a column. GainPerc and SpyPerf are not, so only Gain survives the save. The page still shows the values it just computed.

Clicking the name clones transactions the same way as the portfolio popup, then appends M-Val and Gain. Right-click runs ShowContextMenu on the element id Securities. Investment List writes Negative-Investments-Exported.csv and Positive-Investments-Exported.csv under DownloadsPath, split by the sign of Gain, with ticker, name, gain, and XIRR. A missing downloads path returns without a message.

The chart button calls GraphService.LoadTickerDataAsync(symbol, security.Id).

Other screens

Transactions

No route data: every transaction, ordered by the repo and then by the page sort. State.Year null keeps every trade date. Tickers

GetEntitiesNTAsync<Ticker> and an in-memory sort on symbol or name. No write.

Expenses

Load currencies into a dictionary of Name → Rate where the rate is not 0. Load transactions whose code is not by, sl, li, dv, in, or wd, and whose SecurityID is null. lo is not in that exclusion list. The dropdown lists the distinct codes in that result. No boxes checked means all of those rows. State.Year then keeps only that trade-date year. Null keeps every year. The same value filters Transactions. USD amount is the local amount times the rate for Transaction.Currency looked up as Currency.Name. A missing rate leaves the amount unchanged. Year groups and the grand total sum those USD amounts. LoadMonthBasesAsync loads History where Symbol is Portfolio or CASH. For each month that has a CASH price, it keeps the row dated the 25th, or the latest CASH date in that month when the 25th is missing. The portfolio price for that month is the Portfolio row on the cash date when one exists in the month; otherwise the latest Portfolio date in the month on or before the cash date; otherwise the earliest Portfolio date in the month. The base stored for that year and month is that portfolio price minus the cash price. Symbol Portfolio includes cash, so the difference is the invested book. A month with no portfolio row, a null price, or a difference of 0 is not stored. Perc on a fee row is FormatPerc(AnnualUsd(t), TradeDate): USD × AnnualFactor / that month’s base × 100, invariant culture, two decimals. AnnualFactor reads Transaction.Security: 12 when the text contains Glacier Fees or Management Fee, 3 when it contains Custody Fee, otherwise 1. A missing base or a null USD amount returns an empty string. Year and grand-total Perc are FormatGroupPerc. That adds LineUsd / that row’s month base × 100 for each row that has a base, with no annual factor, and returns an empty string when no row contributes. The USD column is LineUsd and is not multiplied. The code filter and State.Year change which rows are included. Sort is in memory. YearChanged re-runs the filter on the rows already loaded.

Watchlist

  1. Load watchlist rows.
  2. LoadLiveQuotesAsync takes one Yahoo snapshot. Price, change percent, and regular-market time (UTC) stay in a page dictionary. A blank stored name is replaced from long name, then short name, then the symbol, and that name is saved. A Yahoo failure leaves the prices blank and still shows the symbols.
  3. LoadExtHoursAsync calls GetModulesAsync(symbol, ["price"]) four at a time. In market state PRE or PREPRE it prefers preMarketPrice, otherwise postMarketPrice. The page shows that price against the regular price as Ext %.
  4. Add uppercases the box, rejects a duplicate with a page error, snapshots the symbol for a name, and inserts a Watchlist row.
  5. ✕ deletes that row and reloads.
  6. The chart uses LoadAdhocTickerDataAsync. History rows for the symbol are used when any exist. Otherwise Yahoo history for five years is fetched and not written back. The title prefers the watchlist name.

Export

Backup and restore

  1. Backup.OnInitializedAsync lists *.bak in AppConfig.BackupPath and shows the name.bak tail of each path.
  2. The route value becomes the title: Backup or Restore.
  3. Submit with an empty backup path sets ErrorMessage and stays on the page.
  4. Backup uses the text box plus .bak when the box is not empty, otherwise the selected list value. An existing file at that path is deleted first. Repo.SqlBackupAsync runs Use Credo Backup Database Credo to Disk = {path} with init. The database name in that statement is the literal Credo, not AppConfig.DbName.

  6. Success navigates to /. A SQL exception is logged and shown on the form.

XIRR

XirrCalculator is static. CalculateXirr(transactions) builds cash flows and skips any code it does not list.

CodeSign of LocalAmount
by, liNegative (money out)
sl, lo, dv, in, cvPositive (money in)
dp, wd, and anything elseOmitted

The solver is Newton–Raphson from guess 0.1, 200 iterations, tolerance 1e-8, year length 365. A zero derivative or a miss falls through to bisection from -0.999 to 100. Bisection returns 0 when the NPV at the two ends has the same sign or the loop ends. An empty cash-flow list returns 0, which callers then store as 0 percent when they only reject NaN.

CalculateSpyXirr replays by/li/sl/lo as if each buy’s USD amount (LocalAmount * currencyRate) had bought ^GSPC at the first stored S&P price on or after the trade. A sell removes the same fraction of those hypothetical shares. Remaining shares are closed at the latest S&P price. The same solver runs on that series. Callers multiply a finite rate by 100 before display or storage.

The three places that add a cv row (portfolio recalc, menu XIRR, securities ComputeGains) only do it in the list passed to the calculator or the gain sum. They do not insert a cv transaction.

Where flows disagree

These are differences between paths that handle the same idea. Each one is what the current code does.

  • Trade-code case. PDF import stores the lowercase code. Portfolio IRR, menu XIRR, gain math, and expenses compare lowercase literals. GraphService.IsBuy / IsSell ignore case, and the excluded-holdings chart uses those. LoadTickerDataAsync looks for BY, LI, SL, and LO. With lowercase rows the buy and sell dots are empty, and a portfolio-row chart does not jump to the first buy.
  • Portfolio percent. Pct divides the new market value by the sum of market values from before the loop.
  • Yesterday. The non-USD branch multiplies security.PrevClose by the current FX rate. The local variable is named prevFx. The USD=X branch uses previous close, or price when previous close is null, times quantity, with no FX term.
  • Price 1. A missed Yahoo snapshot stores price 1. Portfolio GainPerc is then stored as null. A new PDF holding with no matching security also starts at price 1 until an update finds a ticker.
  • Portfolio chart versus one day of history. The unfiltered toolbar chart reads symbol Portfolio. Update All only upserts today on that symbol. The full reconstruction method is BackfillPortfolioHistoryAsync, and nothing in the UI calls it. Checking Ex switches to the transaction reconstruction, which can be a much longer series.
  • History “rebuild”. Both rebuild methods resume at the last stored date. They add missing dates. They leave an existing today row at its old price. Update All’s daily sync does the same, and it only calls Yahoo history when the last date is before yesterday.
  • Currency name and symbol. Live FX is fetched by Currency.Symbol. Tickers, expenses, and unmatched portfolio rows look up Currency.Name. The CSV map writes the currency column to Name and the symbol column to Symbol.
  • Gain on the securities page versus gain on the portfolio. Securities gain is the signed sum of transaction amounts, plus an in-memory close-out at shares * price, then times currency.Rate unless the security currency is USD=X. Portfolio gain is Market_Value - Cost, and Cost is whatever the holdings PDF stored.
  • Backup database name. Backup SQL hardcodes Credo. Restore uses AppConfig.DbName.
  • Ok dialog. The only ShowMessage caller is the update failure path, and Ok does not complete its task.
  • Transaction dedup. Two different trades on the same date with the same local amount collapse to one row. Security name is not part of the key.
  • Link and securities import. Securities import links only the names it just created. Link Trans is the pass that fixes older rows and Milan-versus-other duplicates.
