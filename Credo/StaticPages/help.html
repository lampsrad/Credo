Credo

Credo is a personal portfolio tracker. It stores your holdings, trades, and prices on this computer, reads broker PDFs and a few CSV files, and pulls live prices from Yahoo Finance. This page explains the menu and every button, so you can find your way around.

A normal day

  1. Credo opens on the portfolio. The menu stays across the top of every screen.
  2. Press ⟳ Refresh. A progress window tracks the price update. When it finishes, the label beside the button changes from Updated Not Yet to a time such as Updated 12s ago. Hover that label for the full date and time.
  3. Press the eye to show dollar amounts. Until you do, $ Value and Gain $ stay blank, and the totals table stays hidden.
  4. Click a security name to see its trades. Click 📈 on a row for that holding’s chart, or the 📈 in the toolbar for the whole portfolio.
  5. When you are finished, press Close in the menu. That quits Credo and closes the browser window it opened.

Green figures are up. Red figures are down.

First-time setup

Do these in order. Each import button lives on Import.

  1. Put Ticker….csv and Currencies….csv in your Downloads\Credo folder. Credo uses the first file whose name starts with Ticker or Currencies.
  2. Tickers — adds symbols that are not already stored.
  3. Currencies — adds currencies and refreshes the names of ones already stored. A new US dollar row is stored with a rate of 1.
  4. Securities — creates a security for every ticker that does not have one yet, and attaches transactions whose security name matches.
  5. Transactions — choose the broker’s transaction-summary PDF. A line already stored with the same trade date and amount is skipped, so an overlapping statement can be imported again.
  6. Link Trans — attaches any remaining transactions to a security of the same name.
  7. Portfolio — choose the broker’s holdings PDF. That file becomes the current holding list.
  8. Update → Update All, or ⟳ Refresh on the portfolio, to fill in live prices.
After an import the screen says Imported: N records for about five seconds. If the CSV folder or file is missing, that count is 0. Closing a PDF dialog without choosing a file leaves your data as it is and shows no message. A holdings PDF with no readable rows shows No holdings found in the PDF. and leaves the current portfolio in place. PDFs larger than 10 MB are refused.

Trade window

Buys are shown as money out. Sells are shown with a negative quantity. If you still hold shares, an M-Val row values them at today’s price. A Gain row totals the result in US dollars. Click the window to close it.

Tickers

The symbol list Credo uses to talk to Yahoo. Click Symbol or Security to sort. There are no other buttons on this screen. Add symbols with Import → Tickers.

Expenses

Cash lines that are not a buy, sell, dividend, or interest, and that are not linked to a security. Typical rows are deposits, withdrawals, and fees. Rows are grouped by year, with a year total and a grand total in US dollars. A year chosen under Years leaves only that year. All includes every year. The code list and the year choice both apply. The dollar conversion uses the exchange rates already stored.

Import

Six buttons down the left side. A button turns red once that import has started, and stays red until you leave the page. Transactions and Portfolio turn red only after you choose a file. Warnings and errors appear under the buttons and stay until the next result replaces them.

ButtonWhat you needWhat it does
Tickers Ticker….csv in Downloads\Credo Adds tickers whose symbol is new.
Currencies Currencies….csv in the same folder Adds new currencies. Existing ones keep their place and have symbol and name refreshed.
Transactions A transaction-summary PDF you choose Reads each trade line: code, description, security, trade date, quantity, currency, and amount. Lines already stored (same date and amount) are skipped.
Securities Tickers already imported Creates a security for each ticker that does not have one, then links transactions that use the same security name. No file dialog.
Portfolio A holdings PDF you choose The PDF becomes the holding list. A name already in the portfolio has its quantity and market value updated. A new name is added. A holding that is absent from the PDF is removed. A line with no market value is skipped, so an older row of that name can be removed with the rest.
Link Trans Securities and transactions already imported Sets the security on transactions whose name matches a security and that are not linked yet. If two securities share a name, the one on the Milan exchange is used. If that still does not pick a single security, Credo lists a warning and leaves those transactions unlinked.
Portfolio replaces the holding list. Import a current holdings PDF. Names missing from that PDF are deleted from the portfolio.

Backup and Restore

Both screens list the .bak files already in the backup folder. A red message on the form tells you if the backup folder is missing or if SQL Server refused the job. A successful run returns you to the portfolio.

ControlWhat it does
Text boxOn Backup, type a name to create a new file. Credo adds .bak. Leave the box empty to use the file selected in the list. If that file already exists, it is replaced.
ListExisting backup files. Restore uses the file selected here.
SubmitRuns the backup or the restore, then opens the portfolio.
Restore replaces the Credo database with the file you selected. Take a backup first if you want to keep the current data.

Update menu

These jobs also run from the menu while you are on any screen. A progress window shows the title and a percent. If a live price update fails, a dialog titled Update Failed shows the reason. Press Ok to close it.

ItemWhen to use it
Update All The everyday price refresh. Fetches live prices, updates securities and exchange rates, recalculates portfolio values and annualized return, and fills any missing daily history for securities and watchlist symbols. ⟳ Refresh on the portfolio does this and then reloads the portfolio.
Recalculate XIRR Recalculates the annualized return stored on each security from the transactions and prices already on file, then opens the portfolio. It does not call Yahoo.
Recalculate Portfolio Recalculates market value, gain, portfolio share, and annualized return from the prices already stored. It does not call Yahoo. Saving a quantity on the portfolio does this as well.
Rebuild Securities History A long job. Fills daily prices for every ticker, going back about five years where history is missing. Use it after you add tickers, or when the charts have gaps. Update All only fills days since the last stored date, so you rarely need this.
Rebuild Watchlist History The same long history fill, for watchlist symbols only. The ⟳ Update History button on the watchlist does this too.

Charts

A chart opens over the page. Click the dark area around it, or press ✕, to close it.

ControlWhat it does

  • Red dots are buys. Green dots are sells.

Transaction codes

These are the codes on the broker statement. Credo stores them in lowercase.

CodeMeaning
byBuy.
slSell.
liLong in. Shares received, including a dividend reinvestment.
loLong out. Shares leaving the account.
dvDividend.
inInterest.
dpDeposit. Shown on Expenses when it is not linked to a security.
wdWithdrawal, including fees described that way on the statement. Shown on Expenses when it is not linked to a security.
M-ValShown only in the trade window. Today’s value of the shares you still hold. It is not a stored transaction.
GainShown only in the trade window. The total result in US dollars. It is not a stored transaction.

Buys and long-ins are treated as money you put in. Sells, long-outs, dividends, and interest are money you received. Deposits and withdrawals stay on the statement and on Expenses. They are left out of the annualized return.
